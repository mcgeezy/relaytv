## Faster, more resilient live controls

RelayTV now delivers live playback and status updates over a versioned
WebSocket to supported browser, Home Assistant, Android, and X11 overlay
clients. Server-Sent Events and HTTP polling remain automatic fallbacks for
older clients and restrictive proxies.

## 🔎 New: discover and request with Seerr

RelayTV now brings Seerr discovery, search, request status, and safe movie or
series requests into the same phone-friendly remote. Operators choose an
explicit shared-administrator or caller-specific identity, while available
media plays only after RelayTV validates it against the active Jellyfin server.
See [Seerr operations](https://github.com/mcgeezy/relaytv/blob/main/docs/SEERR_OPERATIONS.md).
