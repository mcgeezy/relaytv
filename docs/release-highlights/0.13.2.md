## 🔄 New: one-command in-place updates & rollback via `install.sh`

Re-running `install.sh` (or `./install.sh --update`) on an existing host now automatically locates your RelayTV deployment, backs up `.env` and Compose overrides, refreshes release files and hardware discovery while preserving saved display modes, pulls the target image, and verifies `/health` before finishing. If an image pull or post-update health check fails, RelayTV automatically rolls back to your previous image and configuration, with `--branch` / `--image` and `--prune` available for version pinning, manual rollbacks, and old-image cleanup.
